A modern, responsive, and aesthetic personal finance web application built using standard **HTML5, CSS3, and Vanilla JavaScript**.

## 🌟 Key Features

### 1. Key Performance Indicators (KPI Cards)
- **Total Balance**: Real-time liquid cash availability (`Income - Expenses`).
- **Monthly Income**: Incoming earnings with transaction count.
- **Monthly Expenses**: Outgoing spending with percentage of total income.
- **Total Savings Stash**: Accumulated funds across your financial goals and savings deposits.
- **Goals Funded**: Percentage of all financial targets achieved.
- **AI Financial Health Score**: Dynamic rating (0-100) scoring savings rate, budget ratios, and goal progress.

### 2. Smart AI Financial Advisor & Optimization Hub
- **Prioritized Money-Saving Suggestions**: Heuristic engine detecting high-spend categories (e.g. food delivery, dining out, subscriptions) with calculated monthly savings potential.
- **50 / 30 / 20 Budget Rule Meter**: Visual breakdown comparing your actual ratio of *Needs (50%)*, *Wants (30%)*, and *Savings (20%)*.
- **Interactive AI Chat Assistant**: Ask financial questions or tap quick-prompt chips (e.g. *"How can I save $200 more this month?"*, *"Analyze my spending habits"*, *"Am I on track for my goals?"*).

### 3. Financial Goal Planner
- **Custom Goal Creation**: Set target amounts, initial savings, deadline dates, and category icons (🛡️ Emergency, ✈️ Travel, 🚗 Vehicle, 🏡 Real Estate, 💻 Tech, etc.).
- **Monthly Pace Calculator**: Auto-calculates required monthly savings to meet the deadline.
- **Contribute to Goal**: Direct 1-click deposit with option to auto-log in your ledger.
- **Milestone Celebration**: Confetti animation triggers when a goal hits 100%!

### 4. Interactive Visual Analytics (Chart.js)
- **Monthly Cash Flow Breakdown**: Bar chart comparing Income, Expenses, and Net Savings.
- **Expenses by Category**: Donut chart visualizing expenditure distribution.

### 5. Daily Ledger & Expense Manager
- **Categorized Tracking**: Food & Dining, Housing, Utilities, Transportation, Entertainment, Health, Shopping, Salary, Freelance, Investments, and Savings.
- **Live Filtering & Search**: Instant filter by type (*All / Expenses / Income*), category dropdown, or keyword search.
- **CSV Export**: Download your complete ledger with one click.
- **Demo Data Pre-loaded**: Instant preview with realistic fintech transactions and goals.

## 💻 How to Run Locally

You can run the application with Node.js or simply open `index.html` in any browser:

### Option A: Using Node.js (Recommended)
```bash
node server.js
```
Then open: **[http://localhost:3000](http://localhost:3000)**

### Option B: Direct in Browser
Double-click `index.html` or open it directly in Google Chrome, Microsoft Edge, or Firefox.
